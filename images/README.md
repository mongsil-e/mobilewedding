# 이미지 자산

현재 페이지에는 인물 사진을 사용하지 않습니다. 프로필과 스토리 커버는 `index.html`의 SVG 하트·반지 아이콘입니다.

| 파일 | 용도 |
|------|------|
| `just-married-card.png` | 감사 문구를 담은 공유 미리보기, 1200 × 630 |
| `icons/navermap.png` | 지난 청첩장의 네이버 지도 버튼 아이콘 |
| `icons/kakaomap.png` | 지난 청첩장의 카카오맵 버튼 아이콘 |

스토리 본문은 `app.js`의 `STORY_CONTENT`, 감사 글은 `index.html`에서 수정합니다.
공유 이미지의 이름·날짜·문구를 변경하면 PNG와 공유 메타데이터를 함께 갱신합니다.
